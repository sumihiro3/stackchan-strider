手順 1 / 8

デッキにピニオンと左の側板を付ける

  1. ピニオンの歯の側から伸びている長い筒を、側板の丸い穴に内側から通します。
  2. デッキの左側の2本のほぞを、側板の角穴に「カチッ」と止まるまで押し込みます。
  • デッキ ×1
  • ピニオン ×1
  • 側板 ×1

側板は左右とも同じ部品です。突起(スタッド)が外側を向くように付けます。

手順 2 / 8

右の側板とスリーブを付ける

  1. 右の側板を、デッキの右側のほぞに押し込みます。
  2. 短いスリーブを、右の側板の丸い穴に外から差し込みます。
  • 側板 ×1
  • スリーブ ×1

手順 3 / 8

シャフトを通し、クランクを付ける

  1. 六角シャフトを右から差し、スリーブとピニオンに通します。
  2. シャフトの両端にクランクを差し込みます。
  • 六角シャフト ×1
  • クランク ×2

左右のクランクのピンは、必ず反対向き(180°)にします。同じ向きだと歩きません。

手順 4 / 8

ターンテーブル歯車とソケット枠を載せる

  1. 歯車の歯を下に向け、中央の軸をデッキの丸いボスに落とし込みます。
  2. ソケット枠の3つのツメを、歯車の円板の角穴に合わせて載せます。
  • ターンテーブル歯車 ×1
  • ソケット枠 ×1

円板を手で回して、クランクが一緒に回れば歯車は噛み合っています。

手順 5 / 8

ヨークをかぶせる

ヨークを上からかぶせ、側板の4本のツノに「カチッ」と止まるまで押し込みます。輪の内側の返しが、歯車の浮き上がりを押さえます。

  • ヨーク ×1

左右に立っている丸いパッドが、あとでスタックチャンの頭を挟みます。

手順 6 / 8

右側の脚を2本組む

先に机の上で、リンク 4 に三角板を付けた組を4つ作っておきます。リンク 4 の E の突起に上の三角板の E を、G の突起に下の三角板の G を通し、それぞれ突起の溝に C クリップを横からはめます。

  1. クランクを回して、ピンを後ろへ水平に向けておきます。
  2. 後ろ脚のリンク 3 の B を側板の後ろの突起に、リンク 1 の C をクランクのピンに通します。
  3. 三角板の組を重ねます。上の三角板は B と D に、下の三角板は F に入ります。
  4. B と D の突起の溝に、C クリップをはめます。
  5. 前脚のリンク 3 を側板の前の突起に、リンク 1 をピンに通します。
  6. 後ろ脚のリンク 2 を F とピンに通し、F に C クリップをはめます。
  7. 前脚の三角板の組を重ね、B と D に C クリップをはめます。
  8. 前脚のリンク 2 を F とピンに通し、F に C クリップをはめます。
  9. 最後に、ピンの先の溝に C クリップをはめます。
  • リンク 1〜4 各×2
  • 三角板 上下各×2
  • C クリップ ×11

いま組んでいる脚の刻印が光ります。同じ英字どうしをつなぎます。

突起も穴も丸いので、向き合わせは要りません。重ねて、クリップをはめるだけです。前脚は部品が1層ぶん外側に付き、下の三角板は裏返して足先の幅広い部分を内側に向けます。

手順 7 / 8

左側の脚を2本組む

右側と同じ要領ですが、前後が入れ替わります。左側は前脚から組みます。

  1. クランクを回して、左のピンを前へ水平に向けておきます。
  2. 前脚のリンク 3 の B を側板の前の突起に、リンク 1 の C をクランクのピンに通します。
  3. 三角板の組を重ねます(B・D・F)。
  4. B と D の突起の溝に、C クリップをはめます。
  5. 後ろ脚のリンク 3 を側板の後ろの突起に、リンク 1 をピンに通します。
  6. 前脚のリンク 2 を F とピンに通し、F に C クリップをはめます。
  7. 後ろ脚の三角板の組を重ね、B と D に C クリップをはめます。
  8. 後ろ脚のリンク 2 を F とピンに通し、F に C クリップをはめます。
  9. 最後に、ピンの先の溝に C クリップをはめます。
  • リンク 1〜4 各×2
  • 三角板 上下各×2
  • C クリップ ×11

左側では、後ろ脚が1層ぶん外側に付き、下の三角板を裏返すのも後ろ脚です。左のピンは、右のピンと反対向きに付いています。

手順 8 / 8

スタックチャンを載せる

土台をソケット枠のくぼみにはめ、頭を左右のパッドの間に入れます。置くだけで固定は不要です。充電するときは、そのまま持ち上げて外します。

  • スタックチャン(M5Stack 製品版)×1

頭はパッドに挟まれて左右には回れませんが、上下にうなずくことはできます。

完成

首を回すと、歩き出す

首振り(ヨー)のサーボを連続回転させます。頭は回れないので、代わりに土台と歯車が回り、4本の脚が動きます。

  1. ファームウェアを書き込みます(手順はリポジトリの firmware/README.md)。
  2. 画面に出る QR をスマホで読み、家の Wi-Fi を設定します。
  3. つながると操作ページの QR が出ます。読むと、スマホのブラウザに操作ページが開きます。
  4. 「前進」「後退」を押している間だけ歩きます。離すと止まります。

操作ページの QR は、頭の上をさわって離すと、もう一度出せます。

平らな机の上で、速さは 6 割以下が目安です(シミュレーションで 毎秒 約 3 cm)。歩いている間は土台が回り続けるので、USB ケーブルは外します。
