# Stackchan Pivot(ピボット)

M5Stack 製品版スタックチャン(K151 / CoreS3)を載せて走る、3D プリントの車。2 つの駆動輪でまっすぐ走り、頭を上げるとその場で回る。

- スタックチャンが首を振る(ヨー)と、ターンテーブルと歯車を通して左右の駆動輪が回る。左右は 1 本の軸でつながっているので、まっすぐ進む。
- 頭を上げる(うなずき 0° → 30°)と、頭の右側のレバーが押し板を押し下げ、車体の下の足が地面に着く。右の駆動輪が約 3 mm 浮き、左の駆動輪だけが地面を押すので、足を軸に回る。
- 駆動輪はヨークの真下(左右 ±35 mm)にある。足の腕は車体の真ん中をシャフトの下でくぐり、足の先は車軸の 10 mm 後ろ、少し右(x 8〜11 mm)で地面を押す。
- 補助輪は右前と左後ろの対角に 2 個。
- 左の側板の前の下に、倒れ止めの「あご」がある。旋回中は車体が左前へ傾き、左前には支えがないので、後退しながら左へ回り始めると前へ倒れた。あごは旋回中に床から 1 mm 浮いていて、前へ約 1.3° 傾くと床に着く(倒れ始めは約 9°)。
- 首振りを車輪に伝える駆動部(デッキ、ターンテーブルの歯車、ソケット枠、ヨーク、ピニオン)は、[Stackchan Strider](https://github.com/Yeq6X/stackchan-strider)(Yeq6X さん、MIT)の 4 脚ベースの部品を元にしている。
- ネジと接着剤は使わない。C クリップとツメ、LEGO Technic のピン 2 本で留める。

**状態(2026-11-24): 細くする前の形で、実物の直進と旋回ができた。** フローリングの上で、設定は初期値のまま(旋回の角度 30°、速さの上限 60%)。頭を上げると、約 3 秒で半回転した。細くした形(全幅 120 mm、二股の足)も刷って組んだ(2026-11-25)。右へは回れるが、少しずつ位置がずれる。左へは、速さの上限 40% 以上で前へ倒れた(30% では倒れない)。そのため左の側板に倒れ止めのあごを足した。あごを付けて左へ回れるようになったが、少しびっこを引く。右へは途中までしか回らなくなった。足の腕と二股の足がピニオンとタイヤをこすっていた(赤と黒の跡。すきまは設計で 0.7 mm)ので、足の腕を真ん中へ移し、二股をなくした。真ん中の足の腕を刷って組むと、フローリングでは右にも左にも回れた。デスクマットの上では、左へ回るときだけびっこを引く(2026-11-25)。

## 組立ガイド

[`docs_pivot/guide.html`](docs_pivot/guide.html) をブラウザで開く(1 つのファイルで完結する。three.js は CDN から読み込む)。スクロールに合わせて、3D で部品が 1 つずつ付いていく。手順は 10。

順番で間違えやすい所は 4 つ。

1. **デッキ・歯車・ソケット枠・ヨークを、デッキの角のツメ(オリジナルの Strider と同じ縦の留め方)で 1 つのかたまりにしてから裏返し、車軸を上から載せる。** 車軸は、シャフトの少し太い所とスリーブの細い穴で 1 本のかたまりになる。ピニオンは重さで歯車にかみ合ったまま止まる。
2. **ヨークは側板に留めない。** ヨークはデッキの角のツメで留まる。側板は、デッキのツメだけに留める(側板をはめる力が、ヨークの耳にかからない)。
3. **頭のレバーは、スタックチャンを載せたあとで横から付ける。** 先に付けると、輪がヨークの耳に乗り上げて載らない。
4. **押し板は、ファームウェアを書き込み、頭が水平(0°)で止まってからつなぐ。** ほかのファームウェアのままつなぐと、その角度で頭が上がり、足が下りる。

作り直すとき:

```bash
.venv/bin/python car/export_guide_pivot.py
```

## ファームウェアとコントローラー

[`firmware/README.md`](firmware/README.md) を見る。スマホのブラウザから操作する。

| 操作 | 動き |
|---|---|
| スティックを前後に倒す | 頭は水平のまま、前進・後退する |
| スティックを左右に 40% より大きく倒す | 頭を上げて足を下ろし、右なら前進、左なら後退で回る |
| 設定「回るときに頭を上げる角度」 | 10〜30°(初期値 30°)。小さいほど足が浅く下りる |
| 設定「速さの上限」 | 30〜100%(初期値 60%) |
| 設定「回る向きを入れ替える」 | 右と左の旋回を入れ替える |
| 「くるっと 1 回転」(StopWatch の黄) | 「いくよ!」のあと、目をぐるぐるにして 1 回転して止まる(頭のジャイロで数える) |
| 「回り続ける」(StopWatch の青) | 回り続ける。もう一度押す、スティックを動かす、頭をさわる、30 秒、のどれかで止まり、4 秒目を回す |

手に持つコントローラーとして M5Stack StopWatch が使える。

## 実物で確かめたこと(細くする前の形)

- 頭のレバーは、LEGO Technic のピン 2 本で頭の右に留まる。うなずき 0〜30° でこすれない。レバーのピンを押し上げても、頭は浮かない。
- USB-C のケーブルは、レバーの輪の前側をぎりぎり通る。
- フローリングで、直進と、頭を上げての旋回ができる(設定は初期値、輪ゴムなし)。約 3 秒で半回転する。動画のコマから読むと、旋回は右回り(上から見て時計回り)だった。

## 実物で確かめたこと(細くして、足の腕を真ん中へ移した形)

- フローリングで、右にも左にも、びっこを引かずに回れる。
- デスクマット(ゴム系の灰色のマット)の上では、右へは回れるが、左へ回るときだけ止まっては一気に回る(びっこ)。旋回の角度を 25°、20° に下げると小さくなるが、なくならない。
- まっすぐ後退するときと、車体を持ち上げて左旋回の操作をしたときは、つかえない。駆動系ではなく、床とのやりとりで起きている。
- 右前の補助輪は向きの変わらない車輪で、足のまわりを回ると動きの約 74% が横すべりになる。左旋回では、床の摩擦が補助輪を浮かせる向きに働き、浮く・すべる・着くを繰り返していると考えている(補助輪が跳ねるところは見ていない)。直すなら、右前を球(ボールキャスター)かすべり板にする。

## まだ確かめていないこと

- 倒れ止めのあごを付けて、速さの上限 60% で左へ回れるか(あごがないと、40% 以上で前へ倒れた。30% では倒れない。2026-11-25)
- 回るときの位置のずれが小さくなるか(前の足は車軸の 20 mm 後ろで、床をすべりながら回り、少しずつずれた。今は 10 mm)
- 頭を押し上げる反動(約 0.87 N)で、旋回中にスタックチャンが浮かないか
- 旋回中に頭が浮いていないか、直進中に足が床をこすっていないか
- 右前の補助輪が、旋回中に横へ引きずられる影響
- まっすぐ走るときの倒れにくさ(9.3°)が足りるか
- 速さの上限を 100% にしたときの動き
- デスクマットで左旋回のびっこを治す方法(右前の補助輪を球かすべり板にする案)
- 首のサーボの力の余裕と、長く走らせたときの発熱
