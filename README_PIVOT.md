# Stackchan Pivot(旋回車)

M5Stack 製品版スタックチャン(K151 / CoreS3)を載せて走る、3D プリントの車。2 つの駆動輪でまっすぐ走り、頭を上げるとその場で回る。

- スタックチャンが首を振る(ヨー)と、ターンテーブルと歯車を通して左右の駆動輪が回る。左右は 1 本の軸でつながっているので、まっすぐ進む。
- 頭を上げる(うなずき 0° → 30°)と、頭の右側のレバーが赤い押し板を押し下げ、足の腕の先の足が地面に着く。右の駆動輪が約 2 mm 浮き、左の駆動輪だけが地面を押すので、足を軸に回る。
- 車体に足す部品は、左右の側板、頭のレバー、押し板、足の腕の 5 個。ほかはトライクと同じ部品を使う。
- ネジと接着剤は使わない。C クリップとツメ、LEGO Technic のピン 2 本で留める。

**状態(2026-11-24): 実物で、直進と旋回の両方ができた。** フローリングの上で、設定は初期値のまま(旋回の角度 30°、速さの上限 60%)。頭を上げると、約 3 秒で半回転した。

トライク([`README_TRIKE.md`](README_TRIKE.md))は、後輪を切って曲がる作りがうまく動かなかった。この車は、その駆動部をそのまま使い、曲がり方だけを変えたもの。

## 組立ガイド

[`docs_pivot/guide.html`](docs_pivot/guide.html) をブラウザで開く(1 つのファイルで完結する。three.js は CDN から読み込む)。スクロールに合わせて、3D で部品が 1 つずつ付いていく。手順は 10。

順番で間違えやすい所は 4 つ。

1. **足の腕は、右の側板を車体に付ける前に差す。** あとからは、ピニオンに当たって入らない。
2. **デッキだけを先に左の側板へ留めない。** デッキに歯車・ソケット枠・ヨークを重ね、ピニオンをデッキの下から入れてから、左の側板にまとめて留める。デッキを先に留めると、ヨークのツメが側板の角穴に入らない。
3. **頭のレバーは、スタックチャンを載せたあとで横から付ける。** 先に付けると、輪がヨークの耳に乗り上げて載らない。
4. **押し板は、操作ページで「旋回車」を選んでからつなぐ。** 先につなぐと、切り替える前の角度で頭が上がり、足が下りる。

作り直すとき:

```bash
.venv/bin/python car/export_guide_pivot.py
```

## 印刷

| ファイル | 中身 |
|---|---|
| `print_pivot/stackchan_pivot.3mf` | 色ごとのプレート(グレー、赤、黒)。Bambu Lab P2S 用 |
| `print_pivot/stackchan_pivot_1color.3mf` | 1 色で刷るとき。1 枚目が旋回車だけの部品、2 枚目がトライクと同じ形の部品 |
| `print_pivot/stackchan_pivot_step2a_lever.3mf` | 頭のレバーだけ(先に刷って、ヨークの耳と LEGO のピンに合うかを見る) |
| `print_pivot/stackchan_pivot_step2b_rails_link_foot_clips.3mf` | 左右の側板、押し板、足の腕、C クリップ 5 個(トライクから組み替えるとき) |
| `print_pivot/stl/` | 部品ごとの STL(造形時の向き) |
| `print_pivot/parts.json` | 部品表 |

どの部品もサポートは要らない。印刷部品は 20 個。ほかに、LEGO Technic のピン(摩擦つき、2 ポッチの長さ)を 2 本用意する。

トライクから組み替えるときは、左の駆動輪に注意する。トライクの 2 回目の左の駆動輪は丸穴で空転する。この車には、六角穴のもの(トライクの 1 回目と同じ形)を使う。

## 設計と確認

- 設計: `car/pivot_design.py`(駆動部などは `car/car_design.py` と `car/trike_design.py` の部品を使う)
- 干渉、はめ込み、足を下ろしたときの重さの配分の確認:

  ```bash
  cd car && ../.venv/bin/python verify_car.py --model pivot
  ```

- 印刷データの書き出し:

  ```bash
  .venv/bin/python car/build_car.py --model pivot --one-color
  ```

## ファームウェアとコントローラー

[`firmware/README.md`](firmware/README.md) を見る。載せたあと、操作ページの「設定 → 車の種類」で「旋回車」を選ぶ。

| 操作 | 動き |
|---|---|
| スティックを前後に倒す | 頭は水平のまま、前進・後退する |
| スティックを左右に 40% より大きく倒す | 頭を上げて足を下ろし、右なら前進、左なら後退で回る |
| 設定「回るときに頭を上げる角度」 | 10〜30°(初期値 30°)。小さいほど足が浅く下りる |
| 設定「速さの上限」 | 30〜100%(初期値 60%) |

手に持つコントローラーとして M5Stack StopWatch が使える。

## 実物で確かめたこと

- 頭のレバーは、LEGO Technic のピン 2 本で頭の右に留まる。うなずき 0〜30° でこすれない。レバーのピンを押し上げても、頭は浮かない。
- USB-C のケーブルは、レバーの輪の前側をぎりぎり通る。
- フローリングで、直進と、頭を上げての旋回ができる(設定は初期値、輪ゴムなし)。約 3 秒で半回転する。動画のコマから読むと、旋回は右回り(上から見て時計回り)だった。

## まだ確かめていないこと

- スティックを左に倒したときの旋回(後退しながら回る)
- 旋回中に頭が浮いていないか、直進中に足が床をこすっていないか
- 右前の補助輪が、旋回中に横へ引きずられる影響
- 足の腕の左右の振れ(計算では約 2 mm)
- 速さの上限を 100% にしたときの動き
- デスクマットなど、ほかの床での動き
- 首のサーボの力の余裕と、長く走らせたときの発熱
